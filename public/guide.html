EdgePay返回部署向导

INSTALLATION GUIDE

从 License 到 Docker watcher

按顺序完成授权、Worker 部署和容器监听器配置。

01

获取永久 License

  1. 打开 license.imsuk.cn。
  2. 填写准备绑定给支付 Worker 的正式域名，例如 pay.example.com。这里不要填写 license.imsuk.cn。
  3. 免费插件已经锁定为默认包含；按需选择付费插件，也可以全部不选。
  4. 生成后立即复制并妥善保存以 EPL1. 开头的 License。后续增购继续使用同一串 License。
License 与域名严格绑定。部署向导中的“公开访问地址”必须使用同一域名。
02

部署支付 Worker

  1. 回到 deploy.imsuk.cn，填写 Cloudflare API Token 和 Account ID。
  2. 填写项目名、管理员用户名和公开访问地址，例如 https://pay.example.com。
  3. 将刚才保存的 License 粘贴到“EdgePay 永久 License”。向导会在线验签并核对域名。
  4. 客户项目只创建一个 D1；收银台和后台文件已内嵌到 Worker，不会上传 KV 或 Workers Static Assets，因此不会占用对应的存储/命名空间限额。
  5. 确认后开始部署，保存完成页显示的所有密钥，尤其是 ADMIN_TOKEN 和 WATCHER_TRANSPORT_SECRET。
  6. 在 Cloudflare 为支付 Worker 绑定正式域名，保证它与 License 域名一致。
03

启动 Docker watcher

公开镜像同时提供 AMD64 与 ARM64 版本：

docker pull ghcr.io/suk-ldev/edgepay-watcher:latest

新建目录并创建 .env：

mkdir -p edgepay-watcher/storage
cd edgepay-watcher
cat > .env <<'EOF'
TZ=Asia/Shanghai
WORKER_URL=https://pay.example.com
TRANSPORT_KEY=部署完成页的-WATCHER_TRANSPORT_SECRET
EDGEPAY_LICENSE=从-license.imsuk.cn-生成的-EPL1-License
POLL_SECONDS=5
MAX_CONCURRENCY=2
WATCHER_STORAGE_DIR=/app/var/storage
EOF
chmod 600 .env

创建 compose.yaml：

services:
  watcher:
    image: ghcr.io/suk-ldev/edgepay-watcher:latest
    container_name: payment-watcher
    restart: unless-stopped
    env_file: .env
    volumes:
      - ./storage:/app/var/storage
    shm_size: 256mb
    mem_limit: 768m
    security_opt:
      - no-new-privileges:true

拉取并启动：

docker compose pull
docker compose up -d
docker compose ps
docker compose logs -f --tail=100
Worker Secret WATCHER_TRANSPORT_SECRET 与容器 TRANSPORT_KEY 必须完全一致；Worker 和容器也必须填写同一 License。
04

更新与排错

# 更新镜像
docker compose pull && docker compose up -d

# 查看状态和最近日志
docker compose ps
docker compose logs --tail=200 watcher

# 核对实际镜像摘要
docker inspect payment-watcher --format '{{.Image}}'
  • 出现“License 域名不匹配”：检查 WORKER_URL、Worker 的 PUBLIC_BASE_URL 与 License 域名。
  • 出现传输签名错误：重新核对 TRANSPORT_KEY。
  • 浏览器型插件启动失败：确认容器至少有 512 MiB 可用内存，并保留 shm_size。
