打开 Cloudflare API Token 页面 ↗，创建自定义令牌：

  • 账户 · D1 · 编辑
  • 账户 · Workers 脚本 · 编辑
  • 仅上传或更换微信退款证书时：账户 · SSL 和证书 · 编辑

账户资源选择实际部署账号。向导从 Cloudflare 边缘请求 API，不要将客户端 IP 限定为本机 IP；有效期按需设置。证书权限探测异常时，可核对权限后继续，最终以证书上传结果为准。

STEP 02 / 04

填写部署信息

新建项目请设置管理员密码；升级请填写原项目名，原有配置将保留。

项目与管理员

微信支付 V2 API 退款证书（可选）

仅使用微信支付官方 API 且需要原路退款时配置。从微信支付商户平台下载商户 API 证书，两个文件必须一起选择。文件只在当前页面内存和本次部署请求中使用，不写入 EdgePay D1、Worker Secret 或部署日志。

无损升级不选文件会保留现有 WECHAT_MTLS；重新选择两个文件可换证。向导不会自动删除旧证书。
